# T-04: feature-intake: intent first, review tiers, sign-off and WIP gates

- **Roadmap:** ../ROADMAP.md · **Phase:** 1 · **Repo:** gutix · **Base branch:** master · **Branch:** feat/human-ownership-p1
- **Depends on:** T-01 (templates), T-02 (sign-off) · **Model:** main · **Principles:** P1, P2, P4, P6, P7, P11

## Goal
A feature plan starts from Nicolas' own hypothesis and definition of done, marks which tasks a human must read, and
cannot reach main or start its next phase without a sign-off.

## Scope
- `skills/feature-intake/SKILL.md`:
  - Step 1: before drafting, ask once for the hypothesis and the definition of done in the user's words; write them
    into the roadmap. If the user delegates it, write "delegated" there: visible, not hidden.
  - Steps 1 and 3, complex decisions (D14): a decision with real trade-offs or in a human-read area is shown as the
    problem and its options first; ask Nicolas' take; then recommend. Offer to go deeper until Nicolas can argue it.
  - Step 3: templates from `templates/` (relative links); each task gets its Review tier from the repo's human-read
    paths (default list when missing).
  - Step 4 Dispatch: start no task of phase n+1 while release p<n> is not signed off, and nothing new at all while 2
    release lines (any `~/projects/*/docs/features/*/ROADMAP.md`) have a PR and no sign-off for their head (D11).
  - Step 4 Review → Release: after pr-review, `gutix:sign-off` on the release PR; merge only when
    `git diff --name-only <signed-off sha>..HEAD` lists nothing but the roadmap file, or the Log records Nicolas'
    explicit override. Anything else since the sign-off → `gutix:sign-off since=<signed-off sha>` again.
  - Models (D9): dispatch, integrate and phase status sessions start on Haiku; integrate hands off to Sonnet when a
    conflict is more than migration numbering or the combined check fails. Workers stay on Sonnet.
  - Report: the next step names sign-off where it applies.
  - Grow by ≤ 10 lines; trim wording elsewhere.
- Out of scope: the global CLAUDE.md copy of this flow (T-07).
