## Goal
A verify report says, for each green check, which property it proves, and a test added by the change only counts if
it was seen failing without the change or asserts the spec's words.

## Scope
- `skills/verify/SKILL.md`:
  - Report table gains a `proves` column (one short phrase); keep the "not proven" line.
  - Step 3: a test added in this change counts as evidence only if it was seen red without the change (bug-fix's red
    test) or its assertion comes from the spec or acceptance criteria; otherwise report it as "added, not shown to catch
    anything".
  - Models (D9): when verify or impact runs as a subagent from another skill, it runs on Haiku for running and
    reporting; a failure's diagnosis returns to the calling session. One line in each skill.
  - Grow by ≤ 6 lines (verify), ≤ 2 (impact).
- Out of scope: `verify-template.md` (the recipe is unchanged).
