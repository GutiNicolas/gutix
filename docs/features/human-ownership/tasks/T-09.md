## Goal
gutix's current files name no private project, company, client or private repo, and a local check keeps it that way
without publishing the list of names.

## Scope
- Create `~/.claude/private-names.txt` (local, outside every repo): one name or pattern per line. Nicolas confirms the
  list before it is used. Never commit it, never quote it in a public file, PR or commit message.
- In `README.md`, `.claude-plugin/*.json` and every file under `skills/`: replace each match with the generic role it
  plays (the product's e2e repo, the infra/deploy repo, the backend standard skill, the observability standard named in
  the repo's CLAUDE.md, …). Keep the rule, drop the name.
- Where a skill depended on a private specific to work (a repo path, a skill name), it now reads it from the repo's
  `CLAUDE.md` or the global CLAUDE.md, which are private. List each such dependency under Result → Decisions, so
  Nicolas can check the private CLAUDE.md files name them.
- Out of scope: git history (roadmap Q5); gutix-cursor (T-08 ports the cleaned text).
